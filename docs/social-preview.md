# Social preview guidance

Use a 1280×640 image with the title **Local Agentic RAG with Ollama**, the line
**Private answers. Verified sources. Bounded agentic retry.**, and a cropped view
of `portfolio-demo.svg` on a dark background.

Upload it in **GitHub → Settings → General → Social preview**. Keep the title and
source evidence legible at mobile-card size, do not imply cloud hosting, and update
the image whenever the production UI changes materially.
